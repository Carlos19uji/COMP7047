# 📊 Final Proyect MD

## Introduction
Final  Project MD is an applications created to help users to manage their finance and have records of their expenses and their savings.

## 🔍Features
-Allow users to introduce their budgets for different types of expenses such as rent, food, leisure...
-Allow users to introduce their expenses and different 
-Allow users to establish recurrent expenses, for example rent if they pay every month the rent the same day and with the same amount the could be able to establish a recurrent expense and the app will notify them some days before the date to pay the bill.
-Dipslays a summary of the expenses of the user during the month

## 📖 Usage

1. Establish the monthly budgets for each type of expenses.
2. Provide the user the ability to add recurrent expenses.
3. Provide the user  the ability to add expenses.
4. View a monthly summary of each type of expanses and being able to see in detail the expenses of each day of the month.
